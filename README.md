# 🚀 Overview

A robust and scalable Automation Testing Framework built using Selenium, Cucumber, TestNG, Java, and GitHub Actions. The framework supports parallel execution, multi-user pool management, API/UI testing, automatic rerun of failed tests, and Allure reporting. Designed with maintainability, reusability, and CI/CD integration in mind, it enables efficient execution of large-scale regression and smoke test suites.
